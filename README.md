# 文章題ドリル（word-drill-app）

開智小学校（総合部）セカンダリー編入試験（新5年）の **算数・文章題** 対策として、
毎日ちがう数字で類題を無限に作り、A4プリントにして紙で解くためのツール。

計算ドリル（41_calc-drill-app）・漢字アプリ（44_KanjiApp）と同じく、
**単一の `index.html`（ビルド不要）＋ GitHub Pages ＋ 印刷前提** の作り。

## 扱う文章題（開智の過去問の型）

| 型 | 内容 |
|---|---|
| B1 | わり算の逆算（文章）— わられる数＝わる数×商＋あまり |
| B2 | 差から1あたりを出す — 容器＋中身の重さから、1Lの重さと容器の重さ |
| B3 | あまりと公約数 — 何人に分けたかを公約数でもとめる |
| B4 | 小数の1あたり（かけ算・わり算）— 何が1あたりかを決めて計算 |

- れんしゅうレベル 1〜3（やさしい／ふつう／かこもん型）
- 問題数 10・15・20、作成枚数 1〜5日分
- 名前・日付欄／タイム欄／式を書くスペース／スタンプ欄／こたえに式・考え方
- 答えは生成時に数式から確定するので常に正しい（全型×全レベルを検算済み）

設計の経緯は Obsidian `01_Projects/22_Sho5/05_文章題アプリ実行計画.md` を参照。
